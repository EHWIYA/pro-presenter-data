# 문서 규칙

- README는 사람용 빠른 시작, AGENTS는 에이전트용 안내 파일로 유지.
- 세부 정보는 `docs` 한 곳에만 두고 다른 문서에서는 링크로 연결.
- 문서는 한 파일에 한 주제만 기록하고 50줄 이하로 유지.
- 비전공자가 한 번에 이해할 수 있는 짧고 직접적인 표현 사용.
- 설명은 명사형으로 끝내기.
- 행동은 `~하기`, 상태는 `~임`·`~없음`, 주의 사항은 `~금지`·`~필수` 사용.
- 전문용어와 영어 약어는 가급적 제외. 꼭 필요하면 처음 나올 때 쉬운 뜻 병기.
- 명령어, 파일 이름, 코드 식별자는 정확성을 위해 원문 유지.
- 파일과 폴더 이름은 짧은 영문 소문자 사용.
- 변경된 동작과 명령은 같은 커밋에서 문서화.
- 과거 기록보다 현재 운영 절차 우선.
- 링크와 미리 저장한 정보가 최신인지 자동 검사.
