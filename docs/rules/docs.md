# 문서 규칙

- README는 사람용 빠른 시작, AGENTS는 에이전트용 라우터로 유지한다.
- 세부 정보는 `docs` 한 곳에만 두고 다른 문서에서는 링크한다.
- 문서는 한 파일에 한 주제만 기록하고 50줄 이하로 유지한다.
- 비전공자가 한 번에 이해할 수 있는 짧고 직접적인 문장을 쓴다.
- 문장은 주어와 행동이 드러나는 완전한 문장으로 쓴다.
- 제목과 표의 짧은 항목을 제외하고 명사만 나열하는 어미체를 쓰지 않는다.
- 전문용어와 영어 약어는 피한다. 꼭 필요하면 처음 나올 때 쉬운 뜻을 함께 쓴다.
- 명령어, 파일 이름, 코드 식별자는 정확성을 위해 원문 그대로 쓴다.
- 파일과 폴더 이름은 짧은 영문 소문자를 사용한다.
- 변경된 동작과 명령은 같은 커밋에서 문서화한다.
- 과거 세션 기록보다 현재 운영 절차를 우선한다.
- 링크와 문맥 캐시의 최신성을 자동 검사한다.
