# 작업별 문서 안내

| 작업 | 먼저 읽을 문서 |
|---|---|
| 규칙 | `rules/base.md`, `rules/<주제>.md` |
| Git | `repo/git.md`, `rules/git.md` |
| 경로 | `repo/paths.md`, `rules/assets.md` |
| 미디어 | `repo/media.md`, `rules/assets.md` |
| 자동 동기화 | `ops/sync.md`, `repo/git.md` |
| 테마 | `ops/themes.md`, `ops/profiles.md` |
| 글꼴 | `ops/fonts.md` |
| 전체 시스템 | `sys/map.md`, `sys/flow.md`, `sys/pc.md` |

필요한 문서만 찾으려면
`python scripts/ctx.py git|paths|media|sync|themes|fonts` 실행.
