## 컨텍스트 노트

계정명, IP·MAC 주소, 제품 키, 장치 일련번호와 인증 정보는 기록하지 않는다.
빠르게 바뀌는 용량과 실행 상태는 점검 날짜를 함께 적고, 비밀이 없는
명령만 남긴다. 확인 결과는 `docs/sys/pc.md`를 정본으로 사용한다.

USB 오류 코드 43과 파일 교체 재부팅 대기가 재현됨. 유선 연결은 100Mbps,
원격 미디어는 로컬보다 2026-09-13 뉴스 영상 한 개가 많다. 최근 시작 동기화와
rclone 양방향 동기화는 성공했지만 세션 동기화의 이전 종료 코드는 재확인 필요.
