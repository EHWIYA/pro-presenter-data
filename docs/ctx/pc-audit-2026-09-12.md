# 2026-09-12 Windows PC 정보 점검

## 목표

이 저장소와 ProPresenter 운영에 필요한 PC 정보를 다시 확인하고,
민감정보를 제외한 현재 상태와 후속 조치를 재현 가능한 문서로 남긴다.

## 체크리스트

- [ ] 하드웨어와 Windows 버전 확인
- [ ] 저장장치와 네트워크 연결 상태 확인
- [ ] ProPresenter와 동기화 도구 버전 확인
- [ ] 예약 작업과 Git·Nextcloud 설정 확인
- [ ] 문제 장치와 재부팅 대기 상태 확인
- [ ] 시스템 문서와 목차 갱신
- [ ] 전체 검사와 커밋 완료

## 컨텍스트 노트

계정명, IP·MAC 주소, 제품 키, 장치 일련번호와 인증 정보는 기록하지 않는다.
빠르게 바뀌는 용량과 실행 상태는 점검 날짜를 함께 적고, 비밀이 없는
명령만 남긴다. 확인 결과는 `docs/sys/pc.md`를 정본으로 사용한다.
