# 바뀌지 않는 기본 정보

- 저장소 위치는 `%USERPROFILE%\Documents\pro-presenter`.
- GitHub 저장소 주소는 `github.com/EHWIYA/pro-presenter-data`.
- ProPresenter 화면의 재생목록은 `Libraries/*.pro` 파일 사용.
- Git에는 `Libraries`, `Playlists`, `Presets`, `Themes`, `Fonts` 저장.
- `Media/Assets`는 `pp-media`라는 Nextcloud 연결과 양방향 동기화.
- Git에 저장하는 경로는 `%USERPROFILE%\Documents\pro-presenter` 형식.
- 경로 변환 전 ProPresenter 완전 종료.
- 휴대폰 웹 화면과 NAS 서버는 별도 저장소이므로 이곳에서 수정 금지.

현재 브랜치나 변경 파일처럼 자주 바뀌는 정보는 실행할 때 확인.
